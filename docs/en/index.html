Check three things first

  1. If total input already includes cache hits, separate it according to the provider’s definitions to avoid double counting. Usage field meanings can differ across APIs.
  2. Cache writes, tiered rates and rounding can follow separate rules. This tool calculates only the three disjoint categories you enter.
  3. Check HTTP status, usable responses, token usage and recorded charges separately. One successful call does not establish long-term availability.

Formula: sum(tokens × corresponding rate ÷ denominator), then apply the account multiplier.
