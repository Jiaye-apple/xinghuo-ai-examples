复算前先确认三件事

  1. 如果输入总数已经包含缓存命中，请先按服务商定义拆分，避免重复相加。不同接口的 usage 字段可能不同。
  2. 缓存写入、阶梯价格和舍入可能另有规则；这个工具只计算你输入的三类互斥用量。
  3. HTTP 200、回答可用、Token 用量与实际扣费分别验收，不把一次成功当作长期可用率证明。

公式：各类 Token × 对应单价 ÷ 计费单位，求和后再乘账户倍率。
